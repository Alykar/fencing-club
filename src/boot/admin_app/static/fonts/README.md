# Шрифты ULTRA Fencing Club

Положи сюда файлы шрифтов в форматах `.woff2` и `.woff`:

| Вес       | Файл (woff2)                          | Файл (woff)                       |
|-----------|---------------------------------------|-----------------------------------|
| Regular   | `EngraversGothicBT-Regular.woff2`     | `EngraversGothicBT-Regular.woff`  |
| Bold      | `EngraversGothicBT-Bold.woff2`        | `EngraversGothicBT-Bold.woff`     |

Источники: Bitstream Engravers Gothic BT (лицензия требуется).

Можно конвертировать `.otf`/`.ttf` → `.woff2` через https://cloudconvert.com/ttf-to-woff2
